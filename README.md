# modules-project-week6

In this projects I am learning about the module system on Node .js.
How to use the fs and path modules, also how to use and create my custome modules.

## How to use

### Install ts-node

```
npm install ts-node
```

### Install other dependencies

```
npm install
```

### run the program

```
ts-node main.ts
```
